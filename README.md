## Запуск приложения
```bash
cd ПР11_Веб-приложение_по_ТЗ\code
python -m venv venv
venv\Scripts\activate          # Linux: source venv/bin/activate
pip install -r requirements.txt
python seed_demo.py            # тестовые данные
python run.py                  # http://127.0.0.1:5000
```
