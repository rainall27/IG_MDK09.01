# Конференции.РФ

Портал бронирования помещений для проведения Всероссийских конференций (КИМ 09.02.07-3-2027).

## Возможности
- регистрация с валидацией (логин, пароль, ФИО, телефон по маске, e-mail) и вход;
- заявка: помещение (аудитория / коворкинг / кинозал), дата и время начала, оплата (очно / СБП);
- личный кабинет со статусами заявок и отзывами после завершения мероприятия;
- панель администратора (`Conf2027 / Demo77`): все заявки, фильтры, поиск, смена статуса;
- безопасность: хеши паролей, параметризованный SQL, роли, CSRF, защищённые cookie, защита от подбора пароля, CSP;
- адаптивная вёрстка (390×844 → ПК), анимации, оптимизированная графика;

## Запуск
```bash
python -m venv venv
venv\Scripts\activate            # Linux: source venv/bin/activate
pip install -r requirements.txt
python seed_demo.py              # необязательно: тестовые пользователи и заявки
python run.py                    # http://127.0.0.1:5000
```
